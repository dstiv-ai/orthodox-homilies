# Orthodox Homilies

Homilies of the Fathers in clear modern English, with the original Greek alongside — a reading and listening library.

Texts are public domain: St John Chrysostom and the Fathers from *Nicene and Post-Nicene Fathers* (1886–1890) and Migne's *Patrologia Graeca* (1857–1866). Mosaic images from Wikimedia Commons (public domain, photographs by Myrabella). Greek set in GFS Didot (SIL Open Font Licence).

This repository holds the published site only. It is built from a separate working repository.
